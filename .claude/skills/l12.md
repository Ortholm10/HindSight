# L12 — Hindsight universe selection

**Looks like.** The instrument set is chosen using information from the end of
the period — surviving tickers, current index constituents, or symbols filtered
by full-period return or liquidity. The strategy is only ever tested on
instruments that did well enough to still exist.

**Signals.** A symbol list filtered by an aggregate over the full period; a
hardcoded constituent list applied to a historical range.

**Fix.** A point-in-time universe — which usually requires data the user does
not have.

**Report only — never patch, never prove.** L12 is detectable but not patchable.
It is reported as unproven-but-suspected, kept out of the proven findings list,
and belongs in the "what remains unproven" section. The verification hook cannot
be satisfied here, and pretending otherwise would violate the project's own rule.
