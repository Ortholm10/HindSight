# L08 — Forward-window target used as a feature

**Looks like.** A column built from a forward-looking window — forward max,
forward return, triple-barrier label — used in the trading decision rather than
only as a training target. The feature is a transformed copy of the answer;
inflation is extreme.

**Signals.** `rolling(n).max().shift(-n)`, a reversed series (`[::-1]`) followed
by a rolling operation, and any function named `label`, `target`, `barrier`, or
`future_` whose output reaches the signal.

**Fix.** Remove it from the signal path. Keep it as a training target if the
split is chronological.

**Not a leak.** Control C03 — the same construction used only in a reporting
column. The hardest control in the set, and the one every baseline flags.
