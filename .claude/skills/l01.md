# L01 — Explicit future index

**Looks like.** The code names a future row directly. Sharpe usually above 5,
equity curve close to monotonic. The tell is that it looks *too* good.

**Signals.**
- `.shift(` with a negative numeric literal
- `.iloc[i + k]` / `[i+1]` with a positive offset inside a signal function
- `.diff(-n)`, `.pct_change(-n)`

**Fix.** Negate the shift, or remove the column from the signal path.

**Not a leak.** `.shift(-1)` building a forward-return column used only for
reporting (control C03). A negative shift is never conclusive on its own —
what makes it a leak is dataflow into the decision.
