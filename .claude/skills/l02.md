# L02 — Centered rolling window

**Looks like.** `rolling(n, center=True)` labels the window at its midpoint, so
about `n/2` future bars enter every value. Inflation scales with window size,
and the series visibly anticipates turns.

**Signals.**
- `rolling(` with `center=True`
- `scipy.signal.filtfilt` (zero-phase, forward-backward)
- `savgol_filter` applied to the full series

**Fix.** Drop `center=True`; trailing is the pandas default.

**Not a leak.** A centered window built for a chart overlay and never used in
the signal.

**Note.** One-shot LLM baselines miss this often — the line reads as idiomatic
smoothing.
