# L07 — Resample label/closed misalignment

**Looks like.** `df.resample(freq).agg(...)` stamps each bin with a boundary
label. When the label is the bin's *left* edge, the completed aggregate of the
whole period appears at the moment that period began. Strong effect, entirely
ordinary-looking code.

**Signals.** `.resample(` called without explicit `label=` and `closed=` where
the result feeds a signal. Pandas defaults **differ by frequency** — some
calendar frequencies default to right-labelled, others to left — and that
inconsistency is the trap. Flag any bare `resample` on the signal path rather
than encoding per-frequency defaults.

**Fix.** Set `label='right', closed='right'` **and** shift by one period. The
label alone is insufficient: a right-labelled bin is stamped at the instant it
closes, still simultaneous with the decision.

**Not a leak.** Control C08: explicit `label='right', closed='right'` plus a
shift.

**Related.** Co-occurs with [L04](l04.md) in real code. Kept distinct because
the fixes differ.
